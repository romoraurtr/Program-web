
## Rutas 

| Método | Ruta | Descripción |
| :--- | :--- | :--- |
| GET | `/api/games` | Retorna el arreglo completo de juegos registrados. |
| GET | `/api/games/:idGame` | Retorna un juego específico buscando por su ID. |
| POST | `/api/games` | Crea un nuevo juego (ID autoincremental). |
| PUT | `/api/games/:idGame` | Reemplaza totalmente un juego existente. |
| PATCH | `/api/games/:idGame` | Actualiza campos específicos de un juego existente. |
| DELETE | `/api/games/:idGame` | Elimina un juego permanentemente del catálogo. |
